# Counter-Strike Beta 5.0 (LEAK)

- Leaked build from the 20th of December, 1999 by someone named Shadows.
- Also known as version `0.5.39` according to its `liblist.gam`. 
- Build was preserved and shared by **nirv** (thank you !).
- The initial archive did not contain any `cstrike` folder, only its contents.

## Supported versions
- [x] **Windows**
- [ ] **Linux**

## Recommended Half-Life / HLDS version to play
- Windows: Half-Life v1.0.1.6

# Known Differences against Beta5.0's release

```
- The Bomb Icon is blue instead of green (similarly to CS Beta 4.0)
- Several voice lines are placeholders or unprocessed.
- Getting a round draw might softlock the whole game (or will restart a round after several minutes)?
- Only 1 map is provided with this build: bd_train which also contain minor map differences.
```
